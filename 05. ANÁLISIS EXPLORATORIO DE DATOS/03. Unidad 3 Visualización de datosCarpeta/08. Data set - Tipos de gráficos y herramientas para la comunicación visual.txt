    "ventas_mes = df_clean.groupby('mes')['ventas_mensuales'].mean().reindex(orden_mes).dropna()\n",

    "fig, ax = plt.subplots(figsize=(11, 4))\n",

    "            xy=(idx_max, ventas_mes.values[idx_max]),\n",

    "| Herramienta | Código | Cuándo usar |\n",

    "| Texto libre | `ax.text(x, y, 'txt')` | Comentario sin señalar punto |\n",
    "| Línea horizontal | `ax.axhline(y=val, color=, linestyle=)` | Umbral, promedio |\n",
    "| Línea vertical | `ax.axvline(x=val, color=, linestyle=)` | Fecha, corte |\n",
    "| Formas | `patches.Circle/Rectangle(...)` | Resaltar zonas |\n",
